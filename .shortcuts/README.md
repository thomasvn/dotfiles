# macOS Shortcuts

## Shortcuts

- `ChangeBrightness.shortcut` - Uses [`m1ddc`](https://github.com/waydabber/m1ddc) to set external display brightness
- `CleanURL.shortcut` - Removes tracking parameters from clipboard URLs
- `GithubURL.shortcut` - Converts GitHub URLs from clipboard into clean Markdown links
- `JiraURL.shortcut` - Converts Jira URLs from clipboard into clean Markdown links

## Export

1. Select shortcut in Shortcuts app
2. **File** → **Export...**
3. Save to `.shortcuts` directory

## Import

1. Open Shortcuts app
2. **File** → **Import Shortcuts...**
3. Select `.shortcut` file(s)

Or double-click `.shortcut` files or drag them into the app.

**Note:** Some shortcuts require permissions on first run.
